Browser Overlay Fix by RovianDev.

Application ID: io.github.roviandev.browseroverlayfix

Source: https://github.com/RovianDev/BrowserOverlayFix

An LSPosed modern API 102 module that makes browser permission dialogs respond when trusted overlays such as Panels cause obscured-touch warnings. The user still chooses Allow or Deny. It reduces Java tapjacking protection in selected browsers and does not alter Android's permission controller.

Browser Overlay Fix v1.0.0 is tested and working with Panels in Opera, Chrome, Brave, Microsoft Edge, Firefox, Vivaldi and DuckDuckGo. Samsung Browser is expected to work but has not been tested.
